# 💰 Expense Logger

A modern and user-friendly expense management web application built with Flask.

Expense Logger helps users record, manage, search, filter, and analyse their daily expenses through a clean and responsive dashboard.

## ✨ Features

- 📊 Expense dashboard
- 💰 Total spending statistics
- 📈 Average expense calculation
- 🏷️ Category-wise spending
- ➕ Add expenses
- ✏️ Edit expenses
- 🗑️ Delete expenses
- 🔍 Search expenses
- 🏷️ Filter by category
- ↕️ Sort expenses by date and amount
- 🛡️ Form validation
- 📅 Date validation
- ⚠️ Custom 404 and 500 error pages
- 📱 Responsive user interface

## 🛠️ Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- SQLAlchemy
- HTML5
- CSS3
- Bootstrap 5
- Jinja2
